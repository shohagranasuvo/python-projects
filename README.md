# Python Learning Projects

A collection of Python exercises and small projects documenting a path toward AI and machine learning.

## Contents

- `IfElse.py` and `printFirst.py` — introductory Python exercises
- `tictac game/` — a small game project

## Status

Learning and practice repository. Individual scripts may have independent prerequisites.

## Usage

Run a script with Python 3 from the directory containing it. Review the source first because this archive does not define one shared application entry point.
